ГОТОВАЯ ДЕМОВЕРСИЯ САЙТА «БЕЛЫЙ ДЕНЬ»

Открытие на компьютере
Распакуйте архив целиком и откройте index.html. Папки css, js и images должны остаться рядом с ним. Для шрифта Google Fonts требуется интернет; без него используется запасной шрифт.

Обновление существующего сайта
1. Откройте https://github.com/GLOBAL134/my-site555 и войдите в свой аккаунт.
2. В корне репозитория выберите Add file → Upload files.
3. Перетащите index.html и папки css, js, images из распакованного архива. Не загружайте сам ZIP или внешнюю папку архива.
4. Сохраните изменения кнопкой Commit changes в ветку main, если именно из неё уже публикуется сайт.
5. Дождитесь завершения публикации GitHub Pages и обновите страницу сайта.

Формы
Это демонстрация для показа потенциальным заказчикам. Формы проверяют заполнение, но не отправляют и не сохраняют данные. После проверки выводится соответствующее сообщение. Для реальной работы необходимо подключить согласованный канал приёма обращений и поставить контакты заказчика.

Перед передачей покупателю
Замените название, тексты, цены и фотографии на материалы покупателя. Публикуйте только подтверждённые истории проектов. Добавьте реальные контакты, подключите приём обращений, затем удалите пометки о демоверсии.

Проверка
Проверены синтаксис JavaScript, логика меню и форм, структура HTML, уникальность идентификаторов, внутренние ссылки и наличие локальных файлов. Визуальная проверка в браузере обновлённой версии не завершена. На GitHub эта версия автоматически не опубликована.
